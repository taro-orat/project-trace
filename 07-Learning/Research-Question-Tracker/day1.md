
今天的问题

如果一段记忆被输入电脑，并被保存成文字或数据，它还是原来的记忆吗？
还是说，从它被记录下来的那一刻开始，它就已经从记忆变成了某种新的痕迹？



今天做了什么

今天第一次建立 Project Trace 的开发环境，并开始让电脑接收和保存人的输入。



我尝试了

用 Python 接收文字输入
把输入保存成文件
建立项目结构
使用 Git / GitHub 保存项目版本
开始让记忆成为程序能够读取和处理的内容



我实际观察到

人的记忆原本是模糊带有情绪的。
但当它进入电脑以后，首先必须被转化为某种明确的形式，就今天来说是文字。
电脑并不知道这段记忆对我意味着什么，它只能先把它看成可以读取、保存和再次调用的数据。
记忆在进入程序或者说数字世界的一开始，就已经被重新翻译了。



这个结果让我产生了什么新问题

如果记忆必须先被转化成文字和数据，才能被程序或ai处理，那么在这个转化过程中，是否已经有一部分东西消失了？
电脑保存下来的究竟是记忆本身，还是记忆留下的数字痕迹？
如果同一段记忆用不同方式记录，最后留下的痕迹会不会也不同？




Key Terms

记忆 / Memory
痕迹 / Trace
数字痕迹 / Digital Trace
转译 / Translation
数据化 / Datafication
记录 / Recording
输入 / Input



English Seed

A memory changes as soon as it enters a digital system.
What is stored by the computer may not be the memory itself, but a digital trace of it.
This makes me interested in what is lost during the process of translating memory into data.
