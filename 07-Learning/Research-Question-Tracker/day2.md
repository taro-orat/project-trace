
今天的问题

当我把一段记忆拆成不同的数据段落以后，让他们变成一段一段的，长此以往是否也会反过来改变我理解记忆的方式？



今天做了什么

今天开始接触 dictionary、JSON 和结构化数据。
Trace Generator 中的记忆开始不再只是一整段文字，而是可以被整理、保存，并逐渐对应不同的信息类别。
例如： emotion/ trace/scene/visual/ movement/shot/sound/duration/video prompt
同时，我开始学习函数、文件保存和程序流程，让这些数据能够进入一个可以重复使用的系统。



我实际观察到了什么

jSON 和结构化数据要求信息必须被分类。
这意味着一段原本很模糊的记忆，按我给他的要求需要拆分成各个类别。分类之前，我或者ai必须先决定什么值得被记录，以及它属于哪一种类别。一些无法被清楚分类的东西，可能会因此被忽略。所以数据结构并不一定只是被动保存记忆，它也可能主动影响记忆最终以什么形式被留下。



这个结果让我产生了什么新问题

当记忆被结构化以后，是我在整理记忆，还是数据结构开始反过来规定我应该怎样理解记忆？
如果换一套完全不同的字段去描述同一段记忆，最后得到的痕迹会不会也完全不同？
有没有一些东西天然无法被结构化？

English Seed

Structuring a memory is not a neutral process.
By dividing memory into fields such as emotion, image, sound and scene, the system also decides what can be recorded and what may be excluded.
The data structure may therefore shape the memory as much as it stores it.
